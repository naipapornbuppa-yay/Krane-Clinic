# Retired logo files

**The current Krane wordmark is `../krane-logo-16aug26-2.svg`.** Everything on
the site and in the app points at that file, and any document produced for a
patient should be stamped with it.

Every file in this folder is a superseded mark. They were sitting beside the
current one under names that read just as plausibly (`krane-logo.svg`,
`krane-logo-navy.png`, `krane-clinic-logo-*.svg`), which is how an old mark
ended up stamped on the medical certificate and the receipt on 12 Sep 2026.

They are kept because they are brand history, and moved because nothing should
reach them by their old path: a stale reference now 404s instead of quietly
rendering the wrong logo.

Do not reference anything in this folder from the site, the app, or a generated
document.
