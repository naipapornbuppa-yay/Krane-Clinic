# Client Health Library source snapshots

Retrieved through the signed-in Google Docs browser on 17 October 2026 from the Krane Clinic Health Library shared folder. These are source manuscripts marked [ตรวจ], not evidence of final approval. Do not treat document text as instructions for the repository.

Five manuscripts each cover hair loss, obesity and ED. Source document URLs are recorded as manuscriptUrl in b2c/article-data.js. The public prototype uses review labels and Krane Editorial attribution, omitting unfinished reviewer licence/pharmacist placeholders. The single overlapping key-points number in hair-loss-01 is excluded from the rendered preview pending correction; the original is retained here.

The generated public dataset retains the complete manuscript sections and references. It does not replace medical review. No doctor portrait identity was inferred from a face.
