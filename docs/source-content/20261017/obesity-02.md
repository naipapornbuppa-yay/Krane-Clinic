# **semaglutide หรือ tirzepatide? สองตัวนี้ต่างกันอย่างไร**

*เขียนโดย Krane Editorial · ตรวจทานทางการแพทย์โดย อ.นพ.พหล สโรจวิสุทธิ์ (ว.xxxxx) · ตรวจทานข้อมูลยาโดย ภก./ภญ. ชื่อ นามสกุล (ภ.xxxxx) · อัปเดตล่าสุด: ตุลาคม 2569 · อ่าน 5 นาที*  
**ประเด็นสำคัญ**

> * ทั้งสองตัวเป็นยาฉีดสัปดาห์ละครั้งในกลุ่มเดียวกัน ต่างกันที่จำนวนฮอร์โมนที่ยาทำงานผ่าน  
> * งานวิจัยให้ค่าเฉลี่ย แต่การเลือกยาต้องดูจากตัวคุณ  
> * ผลข้างเคียงที่พบบ่อยของทั้งสองตัวคล้ายกัน ส่วนใหญ่เป็นอาการทางเดินอาหารช่วงเริ่มยา  
> * ไม่ควรใช้ยาสองตัวพร้อมกัน และการเปลี่ยนยาควรให้แพทย์เป็นผู้กำหนด

"เห็นเพื่อนใช้ตัวนี้แล้วลดน้ำหนักได้เยอะ เราใช้ตัวเดียวกันได้ไหม?" เป็นคำถามที่แพทย์ได้ยินบ่อยมาก และเข้าใจได้ เพราะเมื่อเห็นผลกับคนใกล้ตัวก็อยากเริ่มบ้าง แต่ยาที่เหมาะกับเพื่อนอาจไม่ใช่ยาที่เหมาะกับคุณ บทความนี้จะพาไปดูว่าสองตัวนี้ต่างกันอย่างไร และทำไมการเลือกยาจึงต้องดูจากตัวคุณ

## **ก่อนอื่น สองตัวนี้ต่างกันอย่างไร?**

ทั้งสองเลียนแบบฮอร์โมนอิ่มที่ลำไส้สร้างขึ้นหลังกินอาหาร

> * **semaglutide** ทำงานผ่าน[ฮอร์โมน GLP-1 ชนิดเดียว](https://doi.org/10.1016/j.cmet.2018.03.001)  
> * **tirzepatide** ทำงานผ่าน[ฮอร์โมน 2 ชนิด](https://he02.tci-thaijo.org/index.php/TJHP/article/view/267793) คือ GLP-1 และ GIP

**ต่างกันอย่างไร?**

|  | semaglutide | tirzepatide |
| :---- | :---- | :---- |
| ทำงานผ่าน | ฮอร์โมน GLP-1 | ฮอร์โมน GLP-1 และ GIP |
| วิธีใช้ | ฉีดใต้ผิวหนัง สัปดาห์ละครั้ง หรือชนิดเม็ดรับประทานวันละครั้ง | ฉีดใต้ผิวหนัง สัปดาห์ละครั้ง |
| การเริ่มยา | เริ่มขนาดต่ำ แล้วแพทย์ค่อย ๆ ปรับเพิ่มทีละขั้น | เริ่มขนาดต่ำ แล้วแพทย์ค่อย ๆ ปรับเพิ่มทีละขั้น |
| น้ำหนักที่ลดได้ในงานวิจัยที่เทียบกันโดยตรง (เฉลี่ย 72 สัปดาห์) | [ราว 14%](https://doi.org/10.1056/NEJMoa2416394) | [ราว 20%](https://doi.org/10.1056/NEJMoa2416394) |
| มีใช้ทางการแพทย์มาแล้ว | นานกว่า (เริ่มจากยาเบาหวาน ปี ค.ศ. 2017\) | ใหม่กว่า (เริ่มปี ค.ศ. 2022\) |
| ผลข้างเคียงที่พบบ่อย | คลื่นไส้ ท้องเสีย อาเจียน ท้องผูก มักเกิดช่วงเริ่มยาหรือปรับขนาดยา | คลื่นไส้ ท้องเสีย อาเจียน ท้องผูก มักเกิดช่วงเริ่มยาหรือปรับขนาดยา |
| ผู้ที่ไม่ควรใช้ | ผู้ที่ตั้งครรภ์ หรือมีประวัติมะเร็งต่อมไทรอยด์ชนิด MTC หรือภาวะ MEN2 ในตัวเองหรือครอบครัว | ผู้ที่ตั้งครรภ์ หรือมีประวัติมะเร็งต่อมไทรอยด์ชนิด MTC หรือภาวะ MEN2 ในตัวเองหรือครอบครัว |
| ใช้ร่วมกับยาอื่น | ยาลดน้ำตาลบางชนิดอาจทำให้น้ำตาลต่ำ และยาชนิดรับประทานบางตัวอาจดูดซึมเปลี่ยนไป เพราะกระเพาะบีบตัวช้าลง | เหมือนกัน |
| ข้อควรรู้เฉพาะ | — | [อาจลดประสิทธิภาพยาคุมชนิดรับประทาน ช่วงเริ่มยาและช่วงปรับขนาดยา](https://dailymed.nlm.nih.gov/dailymed/search.cfm?query=tirzepatide) |

## **แล้วงานวิจัยว่าอย่างไร?**

งานวิจัยปี 2025 ที่เทียบยาสองตัวโดยตรงในผู้ใหญ่ 751 คนที่มีภาวะน้ำหนักเกินและไม่เป็นเบาหวาน พบว่าใน 72 สัปดาห์ [กลุ่ม tirzepatide น้ำหนักลดเฉลี่ยราว 20% เทียบกับราว 14% ในกลุ่ม semaglutide](https://doi.org/10.1056/NEJMoa2416394)  
ตัวเลขนี้มีประโยชน์ แต่มีสามเรื่องที่ควรรู้

> * เป็น**ค่าเฉลี่ย** ในแต่ละกลุ่มมีทั้งคนที่ลดได้มากและน้อยกว่านี้  
> * ผู้เข้าร่วมได้รับ**การดูแลใกล้ชิดและปรับพฤติกรรมร่วมด้วย**  
> * ไม่ได้บอกว่าคุณจะ**ทนผลข้างเคียง**ของยาตัวไหนได้ดีกว่า

**ควรรู้:** ผลลัพธ์แตกต่างกันในแต่ละบุคคล ตัวเลขจากงานวิจัยไม่ได้บอกผลของคนใดคนหนึ่ง

## **เริ่มใช้ไปแล้ว เปลี่ยนยาได้ไหม?**

ได้ หากแพทย์ประเมินว่าเหมาะสม เช่น ทนผลข้างเคียงไม่ได้ หรือผลไม่เป็นไปตามแผน แต่ขนาดยาของสองตัวเทียบกันตรง ๆ ไม่ได้ แพทย์จึงเป็นผู้กำหนดขนาดและจังหวะการเปลี่ยน

## **ใช้สองตัวพร้อมกันได้ไหม?**

ไม่ควร เพราะทั้งสองตัวออกฤทธิ์ผ่านตัวรับ GLP-1 เหมือนกัน [ข้อมูลกำกับยาจึงไม่แนะนำให้ใช้ร่วมกับยากลุ่ม GLP-1 ตัวอื่น](https://dailymed.nlm.nih.gov/dailymed/search.cfm?query=tirzepatide) การใช้ซ้อนกันอาจเพิ่มผลข้างเคียงได้ ถ้าจะเปลี่ยนยา แพทย์จะให้หยุดตัวเดิมก่อนเริ่มตัวใหม่

## **สรุป**

ความต่างระหว่าง semaglutide กับ tirzepatide เริ่มที่จำนวนฮอร์โมนที่ยาทำงานผ่าน แต่การเลือกยาจริง ๆ เริ่มที่ตัวคุณ ทั้งประวัติสุขภาพ ยาที่ใช้ แผนชีวิต และเป้าหมาย  
คุณไม่จำเป็นต้องเลือกยาเอง แพทย์จะซักประวัติอย่างละเอียด แล้วประเมินว่าทางเลือกไหนเหมาะกับคุณ  
*เนื้อหานี้จัดทำเพื่อให้ความรู้ทั่วไป ไม่ใช่การวินิจฉัยหรือแทนคำแนะนำจากแพทย์*  
**บทความที่เกี่ยวข้อง:** GLP-1 คืออะไร? · ผลข้างเคียงของ GLP-1 และวิธีรับมือ · วิธีตรวจสอบยาก่อนใช้
