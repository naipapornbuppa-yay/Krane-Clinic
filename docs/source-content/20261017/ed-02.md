# **ยารักษา ED ชนิดรับประทานมีอะไรบ้าง? คำถามที่แพทย์ต้องรู้ก่อนเลือกยาให้คุณ**

**ประเด็นสำคัญ**

> * sildenafil และ tadalafil เป็นยาชนิดรับประทานที่ทำงานแบบเดียวกัน  
> * ความต่างหลักคือระยะเวลาที่ยาออกฤทธิ์ และความสะดวกในการใช้  
> * ยาที่เหมาะกับคุณขึ้นอยู่กับหลายปัจจัย แนะนำให้ปรึกษาแพทย์เพื่อประเมินก่อนเริ่มใช้

"ฉันควรกินยาตัวไหนดี" เป็นคำถามแรก ๆ ของคนที่เริ่มหาข้อมูลเรื่องภาวะหย่อนสมรรถภาพทางเพศ ยาที่ใช้กันบ่อยอยู่ในกลุ่มเดียวกัน ทั้งนี้ตัวที่เหมาะกับเพื่อน อาจไม่ใช่ตัวที่เหมาะกับคุณ บทความนี้อธิบายความต่างในทางปฏิบัติ และสิ่งที่แพทย์ดูก่อนเลือกยา

## **ยากลุ่มนี้มีอะไรบ้าง?**

[ยาชนิดรับประทานที่ใช้ดูแลภาวะนี้](https://www.mayoclinic.org/diseases-conditions/erectile-dysfunction/in-depth/erectile-dysfunction/art-20047821)อยู่ในกลุ่ม PDE5 inhibitors เช่น sildenafil, tadalafil, vardenafil และ avanafil ทุกตัวช่วยให้เลือดไหลไปที่อวัยวะเพศได้ดีขึ้นเมื่อมีการกระตุ้นทางเพศ บทความนี้เน้น 2 ตัวที่พบบ่อย คือ sildenafil และ tadalafil ซึ่งในไทย[จัดเป็นยาควบคุมพิเศษทั้งคู่ ต้องมีใบสั่งแพทย์](https://fdasamutsongkhram.org/%E0%B8%95%E0%B8%A3%E0%B8%A7%E0%B8%88%E0%B8%9E%E0%B8%9A%E0%B8%8B%E0%B8%B4%E0%B8%A5%E0%B9%80%E0%B8%94%E0%B8%99%E0%B8%B2%E0%B8%9F%E0%B8%B4%E0%B8%A5-sildenafil-%E0%B9%81%E0%B8%A5%E0%B8%B0%E0%B8%97/)  
**ต่างกันอย่างไรในทางปฏิบัติ**

|  | sildenafil | tadalafil |
| :---- | :---- | :---- |
| ออกฤทธิ์นานราว | [4–5 ชั่วโมง](https://www.mayoclinic.org/diseases-conditions/erectile-dysfunction/in-depth/erectile-dysfunction/art-20047821) | [นานถึง 36 ชั่วโมง](https://www.nhs.uk/medicines/tadalafil/) |
| มื้ออาหาร | อาหารมันมากอาจทำให้ยาออกฤทธิ์ช้าลง | ใช้พร้อมหรือไม่พร้อมอาหารก็ได้ |
| รูปแบบการใช้ | ใช้เมื่อต้องการ | ใช้เมื่อต้องการ หรือแพทย์อาจประเมินให้ใช้ทุกวัน |
| ผลข้างเคียงที่พบบ่อย | ปวดศีรษะ หน้าแดง คัดจมูก การมองเห็นเปลี่ยน | ปวดศีรษะ อาหารไม่ย่อย ปวดหลัง ปวดกล้ามเนื้อ |

ระยะเวลาที่นานกว่าไม่ได้แปลว่าดีกว่าเสมอไป บางคนชอบยาที่ออกฤทธิ์สั้นและจบในช่วงเวลาที่ต้องการ บางคนชอบความยืดหยุ่นที่ไม่ต้องวางแผนเวลามาก เรื่องนี้ขึ้นกับไลฟ์สไตล์ของแต่ละคน

## **มียาตัวไหนอันตรายน้อยกว่าไหม?**

ทั้งสองตัวมีข้อห้ามสำคัญเหมือนกัน คือ[ห้ามใช้ร่วมกับยากลุ่มไนเตรตและป๊อปเปอร์](https://www.nhs.uk/medicines/tadalafil/) และผลข้างเคียงส่วนใหญ่ไม่รุนแรงทั้งสองตัว ความเสี่ยงจึงขึ้นกับตัวคุณมากกว่าตัวยา เช่น โรคหัวใจ ความดัน และยาที่ใช้อยู่ นี่คือเหตุผลที่คำถามของแพทย์สำคัญกว่าการเลือกยาจากรีวิว

## **4 คำถามที่แพทย์มักถามก่อนเลือกยา**

**1\. "มีโรคหัวใจ ความดัน หรือโรคประจำตัวอะไรไหม?"** ยากลุ่มนี้มีผลต่อความดันโลหิต ผู้ที่[เคยมีภาวะหัวใจขาดเลือดหรือโรคหลอดเลือดสมองในช่วง 6 เดือนที่ผ่านมา หรือมีความดันที่ยังควบคุมไม่ได้](https://www.mayoclinic.org/diseases-conditions/erectile-dysfunction/in-depth/erectile-dysfunction/art-20047821) ต้องได้รับการประเมินก่อน  
**2\. "ใช้ยาอะไรอยู่บ้าง?"** นอกจากยากลุ่มไนเตรต [ยาบางกลุ่ม เช่น ยาลดความดันกลุ่ม alpha-blocker และยาต้านเชื้อราหรือยาต้านไวรัสบางตัว](https://www.mayoclinic.org/diseases-conditions/erectile-dysfunction/in-depth/erectile-dysfunction/art-20047821) อาจทำให้ความดันหรือระดับยาในร่างกายเปลี่ยน ควรบอกแพทย์ถึงสมุนไพรและอาหารเสริมที่ใช้อยู่ด้วย  
**3\. "อาการเป็นมานานแค่ไหน และเกิดในสถานการณ์ไหน?"** ช่วยให้แพทย์แยกว่าสาเหตุมาจากร่างกาย จิตใจ หรือทั้งสองอย่าง  
**4\. "ชีวิตประจำวันของคุณเป็นอย่างไร?"** เช่น ต้องการความยืดหยุ่นเรื่องเวลาแค่ไหน และดื่มแอลกอฮอล์บ่อยไหม เพราะ[แอลกอฮอล์เพิ่มโอกาสความดันต่ำ](https://www.nhs.uk/medicines/tadalafil/) ข้อมูลนี้ช่วยให้แพทย์เลือกตัวที่เข้ากับคุณ  
ถ้าลองใช้ยาแล้วยังไม่ได้ผลลัพธ์ที่ต้องการ แพทย์อาจปรับแผนหรือเปลี่ยนยาได้

## **สรุป**

sildenafil กับ tadalafil ไม่ได้แข่งกันว่าตัวไหนดีกว่า แต่ต่างกันที่ระยะเวลาและความสะดวก ตัวที่เหมาะขึ้นกับไลฟ์สไตล์ของคุณ  
คุณไม่จำเป็นต้องเลือกยาเอง แนะนำให้ปรึกษาแพทย์เพื่อประเมินว่าวิธีไหนเหมาะกับคุณ  
*เนื้อหานี้จัดทำเพื่อให้ความรู้ทั่วไป ไม่ใช่การวินิจฉัยหรือแทนคำแนะนำจากแพทย์*
