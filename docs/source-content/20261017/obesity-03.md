# **ใช้ยากลุ่ม GLP-1 แล้วจะเจออะไรบ้าง? ผลข้างเคียงในแต่ละช่วง และวิธีรับมือ**

*เขียนโดย Krane Editorial · ตรวจทานทางการแพทย์โดย อ.นพ.พหล สโรจวิสุทธิ์ (ว.xxxxx) · ตรวจทานข้อมูลยาโดย ภก./ภญ. ชื่อ นามสกุล (ภ.xxxxx) · อัปเดตล่าสุด: ตุลาคม 2569 · อ่าน 5 นาที*  
**ประเด็นสำคัญ**

> * ผลข้างเคียงที่พบบ่อยคืออาการทางเดินอาหาร และส่วนใหญ่ไม่รุนแรง  
> * ช่วงที่เจอบ่อยคือสัปดาห์แรก ๆ และหลังเพิ่มขนาดยาแต่ละครั้ง  
> * การกินมื้อเล็ก กินช้า และดื่มน้ำให้พอ ช่วยได้มาก  
> * ผลข้างเคียงไม่ใช่สัญญาณว่ายา "ได้ผล" และไม่ควรฝืนทนคนเดียว

หลายคนกังวลเรื่องผลข้างเคียงมากกว่าเรื่องตัวยาเสียอีก ซึ่งเข้าใจได้ ข่าวดีคืออาการส่วนใหญ่คาดเดาได้ เกิดเป็นช่วง ๆ และมีวิธีรับมือ บทความนี้พาไล่ดูทีละช่วงว่าจะเจออะไร และอะไรที่ไม่ควรมองข้าม

## **ช่วงสัปดาห์แรก ๆ: ร่างกายกำลังปรับตัว**

ยากลุ่มนี้ทำให้อาหารเคลื่อนออกจากกระเพาะช้าลง จึงอิ่มนานขึ้น แต่ช่วงแรกร่างกายยังไม่คุ้น หลายคนจึงรู้สึก

> * คลื่นไส้ แน่นท้อง โดยเฉพาะหลังกินอิ่มเกินไป  
> * ท้องเสียหรือท้องผูก  
> * เบื่ออาหาร อ่อนเพลียบ้างในบางวัน

ในงานวิจัยขนาดใหญ่ [ผู้ใช้ semaglutide ราว 3 ใน 4 คนมีอาการทางเดินอาหารอย่างน้อยหนึ่งครั้ง](https://doi.org/10.1056/NEJMoa2032183) ส่วนใหญ่ไม่รุนแรงและเป็นชั่วคราว ผู้ใช้ tirzepatide ก็มี[อาการคล้ายกัน](https://he02.tci-thaijo.org/index.php/TJHP/article/view/267793)  
**ช่วยได้อย่างไร:** กินมื้อเล็กลงแต่บ่อยขึ้น กินช้า ๆ หยุดเมื่อเริ่มอิ่ม เลี่ยงอาหารมันและทอด และดื่มน้ำให้พอตลอดวัน [งานทบทวนจากคณะแพทยศาสตร์ มหาวิทยาลัยสงขลานครินทร์](https://he03.tci-thaijo.org/index.php/AJHSD/article/view/4643)แนะนำให้เน้นโปรตีนด้วย แม้ช่วงที่ไม่ค่อยหิว เพื่อลดการสูญเสียมวลกล้ามเนื้อ

## **ช่วงเพิ่มขนาดยา: อาการอาจกลับมาชั่วคราว**

แพทย์มักเริ่มจากขนาดต่ำแล้วค่อยเพิ่มทีละขั้น เพื่อให้ร่างกายปรับตัวทัน แต่หลังเพิ่มขนาดแต่ละครั้ง อาการช่วงแรกอาจกลับมาอีกสักระยะ ซึ่งเป็นเรื่องที่พบได้  
ถ้าอาการหนักขึ้นจนรบกวนชีวิตประจำวัน แพทย์อาจคงขนาดเดิมไว้นานขึ้นก่อนเพิ่ม หรือปรับแผนให้ นี่คือเหตุผลที่การติดตามกับแพทย์สำคัญ

## **ช่วงที่ร่างกายปรับตัวแล้ว**

สำหรับหลายคน อาการค่อย ๆ ลดลงจนแทบไม่รบกวน สิ่งที่ยังควรใส่ใจคือดื่มน้ำให้พอ และกินอาหารให้ครบ แม้จะกินได้น้อยลง  
อีกเรื่องเล็ก ๆ ที่มักถูกลืมคือ**ตำแหน่งฉีด** ควรเปลี่ยนจุดฉีดทุกครั้ง เพื่อลดผื่นแดงหรืออาการคันตรงที่ฉีด

## **สัญญาณที่ต้องพบแพทย์ทันที ไม่ว่าช่วงไหน**

**พบแพทย์ทันทีหากมีอาการเหล่านี้** หรือโทร 1669 หากเป็นเหตุฉุกเฉิน

> * ปวดท้องรุนแรงต่อเนื่อง อาจร้าวไปหลัง  
> * ปวดท้องด้านขวาบน มีไข้ หรือตาและตัวเหลือง  
> * อาเจียนหรือท้องเสียจนเก็บน้ำไว้ไม่ได้ ปัสสาวะน้อยมาก เวียนศีรษะ  
> * ใจสั่น เหงื่อออก มือสั่น สับสน (โดยเฉพาะผู้ที่ใช้ยาลดน้ำตาลชนิดอื่นร่วมด้วย)  
> * คลำพบก้อนที่คอ เสียงแหบ หรือกลืนลำบาก  
> * หน้าบวม ปากบวม หายใจลำบาก หรือผื่นขึ้นทั่วตัว

## **คำบอกเล่า vs ความจริง**

| คำบอกเล่า | ความจริง |
| :---- | :---- |
| "คลื่นไส้แปลว่ายากำลังได้ผล" | ผลข้างเคียงไม่ได้บอกว่ายาได้ผลมากหรือน้อย บางคนแทบไม่มีอาการแต่น้ำหนักก็ลดตามปกติ |
| "ต้องอดทนไว้ เดี๋ยวก็หาย" | อาการเล็กน้อยมักดีขึ้นเอง แต่ถ้ารบกวนชีวิตประจำวัน แพทย์ปรับขนาดหรือจังหวะการเพิ่มยาให้ได้ ไม่จำเป็นต้องฝืน |
| "กินน้อยลงแล้ว ไม่ต้องสนใจว่ากินอะไร" | ยิ่งกินได้น้อย ยิ่งต้องเลือกให้ดี โดยเฉพาะโปรตีนและน้ำ เพื่อรักษากล้ามเนื้อและป้องกันการขาดน้ำ |

## **สรุป**

ผลข้างเคียงของยากลุ่ม GLP-1 มักมาเป็นช่วง เด่นชัดตอนเริ่มยาและหลังเพิ่มขนาด แล้วค่อย ๆ ดีขึ้น การปรับวิธีกินช่วยได้มาก และเมื่ออาการเกินกว่าที่ควร การมีแพทย์ที่ติดตามอยู่ ทำให้ปรับแผนได้ทันโดยไม่ต้องฝืนทนคนเดียว  
*เนื้อหานี้จัดทำเพื่อให้ความรู้ทั่วไป ไม่ใช่การวินิจฉัยหรือแทนคำแนะนำจากแพทย์*  
**บทความที่เกี่ยวข้อง:** GLP-1 คืออะไร? · semaglutide หรือ tirzepatide? · ทำไมการออกกำลังกายถึงสำคัญระหว่างใช้ GLP-1
