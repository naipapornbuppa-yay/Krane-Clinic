Consultation room and record

The room opens in video for both people and falls back to voice and chat only when a camera goes off. A finished visit becomes a read-only record: notes with an author, the medicine prescribed, and the photos the patient sent.

Foundation 13

Motion

Motion supports hierarchy and state change. It never delays a clinical or operational task and always respects reduced motion.

Duration and easing

Use the named level that matches the size of the change.

--dur-* / --ease-*
Micro--dur-micro

press, toggle, focus

Base--dur-base

card and component reveal

Page--dur-page

screen transition

Slow--dur-slow

ambient loading only

--ease-out--ease-inout--ease-springprefers-reduced-motion
Developer rule: extend a shared token or component before adding a page-specific value. Every visible action must produce navigation, a state update, or explicit feedback.
