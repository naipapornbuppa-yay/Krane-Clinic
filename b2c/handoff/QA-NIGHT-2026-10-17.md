## Re-run

Use the same B2C tools. `QA_TIMEOUT_FACTOR=20` is the documented allowance used on this host. To reproduce the retry renderer on macOS, create a temporary launcher containing:

```sh
#!/bin/sh
exec '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' --disable-gpu "$@"
```

Make it executable and set `CHROMIUM_PATH` to its path. With normal Chrome, set `CHROMIUM_PATH` to the installed executable instead. Run suites sequentially:

```sh
QA_TIMEOUT_FACTOR=20 node b2c/tools/contract-check.mjs
QA_WIDTH=390 QA_TIMEOUT_FACTOR=20 node b2c/tools/qa-chrome-consistency.mjs
# Repeat QA_WIDTH for 320, 360, 768, 1100, 1440.
QA_TIMEOUT_FACTOR=20 QA_OUTPUT=/tmp/qa-entry node b2c/tools/real-entry-qa.mjs
QA_TIMEOUT_FACTOR=20 QA_OUTPUT=/tmp/qa-review node b2c/tools/review-round-qa.mjs
QA_TIMEOUT_FACTOR=20 QA_OUTPUT=/tmp/qa-edge node b2c/tools/night-edge-qa.mjs
npm run check:strings
# Isolated retry example:
QA_TIMEOUT_FACTOR=20 QA_OUTPUT=/tmp/qa-retry node b2c/tools/review-round-qa.mjs pause-program-persistence
```
