# B2C review QA — 10 October 2026

Scope: the current static patient and partner prototype, including the requested screen removals, shared components, OTP continuation, articles, documents, notifications and referral UI. This report distinguishes browser evidence from backend integration requirements.

## Executed checks

- Focused Playwright regression: 9/9 pass. First phone entered → primary CTA → OTP → insurance; invalid phone stays on form; empty/filled DOB label behavior; mobile document search/sort and no-results; dismissed review reopened from notifications; article filter/detail/author; stationary appointment day; matching duration/relief control geometry; inventory of 63 current screens with retired screens absent.
- Queue lifecycle regression: passed (process exit 0). Includes persisted wait start, resume, expired queue and booking fallback without erasing intake.
- API string contract: 87 unique IDs and matching locale parameters pass.
- JavaScript syntax and Git whitespace checks pass.
- Shared header/logo/navigation browser consistency: 114 page/viewport cases executed. One assertion incorrectly compared selected versus unselected option shadows at 390 px. After fixing state-matched selection, all 19 cases at 390 px passed; the other five widths passed in the full run.
- Full UI/flow contract: all 170 checks passed (63 screens, 44 components, 5 flows, 33 rules).
- Heading spacing: 147 cases, no failures.
- Custom select keyboard/touch, placeholder validation and cascading options: passed.

## Defects found and corrected during QA

- The fee acknowledgement assertion still expected retired copy; it now expects the shared continuation wording.
- New UI strings were absent from the literal translation map; added translations for article cards, notifications, referral text and labels.
- Back from partner OTP left the automatic-continue flag set; back/reset now clears it.
- Hidden file inputs expanded two narrow screens; accessible hidden file inputs now have a 1 px box.
- Relief controls grew taller than duration controls; both now share fixed control geometry.
- Referral popup values/code disagreed with the referral page; the fixtures now agree.
- The consistency test compared selected and unselected option shadows; it now compares unselected options.
- The geometry test selected a hidden duration control on a different screen; selectors now target the visible concern screen. Appointment geometry waits for page-entry motion/fonts before testing hover/click.

## Coverage limits and missing production states

This is a review prototype. Passing its tests is not production acceptance. The detailed matrix in [ERROR-EDGE-CASES.md](../../ERROR-EDGE-CASES.md) records code-review-only and integration cases separately.

Required backend/UI acceptance work includes real OTP expiry/resend/rate limits; insurer no-match, expired coverage and service failure with retry/self-pay; secure ID upload/OCR; no-doctor and booking races; authoritative stock/price changes; payment webhook reconciliation/idempotency; failed/interrupted uploads; offline recovery; and per-order review reminders. Existing mock routes and message IDs do not prove those integrations work.

Localization inventories are not runtime ID binding: 565 active catalog entries lack an English value, and 92 toast call sites still need message-ID mapping. The Thai article body fixtures need complete editorial English content before an English production release. The browser language test covers currently rendered screen copy, not every possible CMS article payload.

CMS article/image/author data remains fixture data with semantic fields; the B2B admin field/feature mapping is intentionally deferred as requested. See [ARTICLE-CMS-NOTES.md](../../ARTICLE-CMS-NOTES.md).

## Reproduce

From repository root, use Node, Python 3 and Playwright. Set `CHROMIUM_PATH` to an installed Chrome executable if bundled Chromium is unavailable.

- `node b2c/tools/contract-check.mjs`
- `node b2c/tools/qa-chrome-consistency.mjs --json`
- `node b2c/tools/review-round-qa.mjs`
- `node b2c/tools/check-string-ids.mjs`
- `node b2c/tools/select-options-check.mjs`
- Queue and heading scripts require the repository served on localhost port 5178.

Detailed transient browser output/screenshots were saved under `/tmp/krane-review-round` on the review machine. This checked-in report preserves the findings; rerun the scripts to regenerate artifacts.
