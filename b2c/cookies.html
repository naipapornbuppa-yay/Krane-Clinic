เว็บไซต์รุ่นนี้ใช้อะไร

คุกกี้และพื้นที่เก็บข้อมูลในเบราว์เซอร์เป็นคนละวิธีจัดเก็บข้อมูล จากการตรวจโค้ดและทดสอบหน้าแรก บทความ ความเป็นส่วนตัว และหน้าทางเข้าระบบด้วยเบราว์เซอร์ใหม่ ไม่พบคุกกี้ที่เว็บไซต์ตั้งขึ้น หรือเครื่องมือวิเคราะห์และโฆษณาในหน้าที่ทดสอบ

เว็บไซต์ใช้ localStorage เพื่อจำภาษา และมีข้อมูลสำหรับฟังก์ชันของระบบตัวอย่างตามรายการด้านล่าง การเปิดอ่านบทความไม่ต้องกดยินยอมให้ติดตามเพื่ออ่านเนื้อหา

ข้อมูลที่จัดเก็บในเบราว์เซอร์

ข้อมูลและวัตถุประสงค์พื้นที่จัดเก็บระยะเวลา

สถานะและข้อมูลร่างในระบบตัวอย่างsessionStorage

เช่น ที่อยู่ คิวปรึกษา เคสตัวอย่าง ตารางแพทย์ และร่างบทความในตัวแก้ไข		ไม่มีวันหมดอายุที่กำหนดในโค้ด จนกว่าฟังก์ชันนั้นหรือคุณจะลบ หรือเบราว์เซอร์ล้างข้อมูล
ไฟล์ที่แนบในระบบตัวอย่าง
krane-clinical-files		IndexedDB
เก็บไฟล์เพื่อเปิดดูในการทดลองขั้นตอนบริการ		จนกว่าคุณหรือเบราว์เซอร์จะลบข้อมูลเว็บไซต์

ข้อมูลของระบบตัวอย่างขึ้นอยู่กับหน้าที่เปิดและการกระทำของคุณ ไม่ได้สร้างทุกรายการเมื่ออ่านหน้าเว็บไซต์ ข้อมูลที่กรอกในระบบตัวอย่างอาจคงอยู่บนอุปกรณ์ที่ใช้ร่วมกัน จึงควรใช้ข้อมูลสมมติในการทดลอง

ผู้ให้บริการเว็บไซต์

เว็บไซต์ที่เผยแพร่บน GitHub Pages ใช้บริการของ GitHub ซึ่งระบุว่ามีการบันทึกที่อยู่ IP ของผู้เข้าชมเพื่อความปลอดภัย ข้อมูลส่วนนี้เป็นการบันทึกโดยผู้ให้บริการโฮสต์ แยกจากข้อมูลที่เก็บในเบราว์เซอร์ของคุณ อ่าน รายละเอียดการเก็บข้อมูลของ GitHub Pages

ลิงก์ออกไปยังเว็บไซต์อื่น เช่น แหล่งอ้างอิงในบทความ จะอยู่ภายใต้นโยบายของเว็บไซต์ปลายทางเมื่อคุณเปิดลิงก์นั้น

จัดการข้อมูลอย่างไร

เปลี่ยนภาษาได้จากเมนูภาษาของเว็บไซต์ หากต้องการลบข้อมูลที่เก็บไว้ ให้เปิดการตั้งค่าความเป็นส่วนตัวของเบราว์เซอร์ แล้วเลือกลบข้อมูลเว็บไซต์สำหรับโดเมนที่กำลังใช้งาน การลบอาจทำให้ภาษากลับเป็นค่าเริ่มต้นและทำให้ข้อมูลร่างหรือไฟล์ในระบบตัวอย่างหายไป

การปิดแท็บจะจบเซสชันตามพฤติกรรมของเบราว์เซอร์ แต่ไม่ลบ localStorage หรือ IndexedDB การบล็อกคุกกี้อย่างเดียวอาจไม่ลบข้อมูลทั้งสองประเภทนี้ คุณจัดการพื้นที่เก็บข้อมูลได้จากการตั้งค่าข้อมูลเว็บไซต์ของเบราว์เซอร์

การปรับปรุงและติดต่อ

รายละเอียดนี้อธิบายการทำงานของเว็บไซต์รุ่นที่ตรวจสอบ หากเพิ่มเครื่องมือวิเคราะห์ โฆษณา หรือบริการภายนอก จะต้องปรับรายการและการตั้งค่าที่เกี่ยวข้องก่อนเปิดใช้งาน ข้อความนี้ไม่ได้ยืนยันการตรวจรับรองด้านกฎหมาย
