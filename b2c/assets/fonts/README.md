# B2C font files

Vendored from the existing Google Fonts CSS dependency, preserving IBM Plex Sans, Noto Sans Thai and Prompt weights 300, 400, 500, 600, 700. Source: https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@300;400;500;600;700&family=Noto+Sans+Thai:wght@300;400;500;600;700&family=Prompt:wght@300;400;500;600;700&display=swap

Licenses are included beside the files. `b2c/fonts.css` declares the faces with `font-display: swap`. Hashed filenames identify the original font URLs.

Inter weights 400–700, previously requested by the embedded landing page, are also included with its OFL license.
