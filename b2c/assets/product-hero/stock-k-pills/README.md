# Krane `k` tablet stock

Reusable transparent product cutouts generated for Krane campaign mockups.

- `krane-k-round-lavender.*` — round lavender tablet
- `krane-k-round-blue.*` — round ice-blue tablet
- `krane-k-rounded-square-blue.*` — rounded-square blue tablet
- `krane-k-oval-blue.*` — oval blue tablet

Each variant is supplied as a transparent PNG master and an optimized WebP. The only debossed mark is the lowercase serif `k`, derived from the leftmost character in `../krane-wordmark.svg`. The images intentionally contain no medicine name, dose, score line, packaging, or manufacturer mark.

Created with built-in ImageGen in precision product-mockup mode. The shared direction was: one dry, matte compressed pharmaceutical tablet with subtle powder micro-grain and shallow bevel; one centered debossed Krane `k`; a flat chroma-key background; and no plastic gloss, extra text, or additional tablets. The chroma field was removed locally and each transparent cutout was cropped to a safe square canvas.
