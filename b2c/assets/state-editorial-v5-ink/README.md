# Krane state illustrations · ink editorial alternative

This directory contains the complete 19-image alternative B2C state set.
It is intentionally separate from the active editorial illustration set.

## Shared art direction

- Hand-drawn black-ink editorial cartoon.
- Expressive variable-width outlines with selected solid-black shapes.
- Loose curves and simplified, playful proportions.
- Warm ivory `#F4F0E4` is the only interior fill.
- Transparent background, no embedded UI, labels, text, logos, or shadows.
- Landscape source canvas: `1080 × 720` RGBA PNG.
- Intended app display box: `560 × 360`, using `object-fit: contain`.

Generated with the built-in ImageGen workflow using the supplied illustration as
a style reference. Flat green chroma sources were converted locally to alpha PNGs,
despilled, resized consistently, and validated for transparent corners and green fringe.
