They use one fictional subject, a square crop (1:1), bright even light,
dry hair, and consistent framing so the set reads as one. They contain no
real patient likeness or personal health data.

If an image cannot load, its tile shows a neutral camera-slot placeholder
so the demo layout stays intact. Replace with client-approved photography
only after confirming consent and usage rights.
