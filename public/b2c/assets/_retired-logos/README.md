# Retired logo files (app copy)

**The current Krane wordmark is `../../../assets/krane-logo-16aug26-2.svg`**, the
same file the site header uses. Nothing else is a Krane logo.

This folder held a second copy of the superseded wordmark family, sitting
beside the app's own assets under names that read as current
(`krane-clinic-logo-*.svg`, `krane-logo-16jul*.svg`). Two directories of
near-identically named logos is why an old mark kept being picked up, including
onto the medical certificate and receipt on 12 Sep 2026.

`krane-mark-*.svg` in the parent folder is the crane symbol, a different asset
from the wordmark, and is not retired.

Do not reference anything in this folder.
